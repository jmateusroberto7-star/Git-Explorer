# Pesquisa de Usuários do GitHub
Um menu de pesquisa inspirado no GitHub que busca usuários reais da plataforma em tempo real!

## Sobre o Projeto
Este projeto é uma interface de pesquisa que permite buscar usuários do GitHub de forma rápida e visualmente parecida
com o menu de pesquisa do próprio site.Ao digitar um nome de usuário, o sistema consulta a API pública do GitHub exibe
os resultados diretamente na tela.

## Funcionalidades
. Pesquisa em tempo real - conforme você digita, os resultados aparecem

. Susgestões rápidas - itens do menu fixos aparecem primeiro

.Busca de usuários reais - conecta com API do GitHub para trazer dados verdadeiros

. Perfil completo - mostra nome,foto, repositórios e seguidores de cada usuário

. Acesso direto - clique no resultado para abrir o perfil no GitHub

. Design responsivo - visual limpo inspirado na interface oficial

## Tecnologias Utilizadas
- HTML5
- CSS3
- Java Script
- API do GitHub


## Estrutura do Projeto
|__index.html  #Página principal
|__estilos.css #Estilos visuais
|__script.js   #Funcionalidades


## Como Usar
1.Baixe os arquivos para o seu computador
2.Abra o arquivo index.html no navegador
3.Digite um nome de usuário do GitHub no campo de pesquisa
4.Veja os resultados aparecendo abaixo automaticamente
5.Clique em usuário para abrir o perfil completo no GitHub
